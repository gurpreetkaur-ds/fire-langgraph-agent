How It Works

  • LangGraph manages the workflow: decompose → answer → synthesize.
  • Fire provides every LLM call — no direct OpenAI, Anthropic, or Gemini calls exist in this app.
  • A custom Fire wrapper (FireChatModel) routes all model requests through /v1/chat.
  • Secrets stay server-side: FIRE_API_KEY lives only in a local .env file, never sent to the browser.
